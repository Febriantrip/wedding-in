# Product modules & journeys

## Commercial and project setup

1. Configure event types, services, vendor offerings, pricing and packages.
2. Prepare a quotation, calculate the offered scope and record its status.
3. Convert an accepted quotation into a wedding project.
4. Track the contract, budget, change orders and revenue versus direct-vendor payments.

## Preparation and event execution

1. Maintain event dates, preparation checklist, team assignments and task calendar.
2. Reschedule with the Gantt timeline and keep dependent checklist dates aligned.
3. Copy the standard rundown template into a wedding-specific rundown; editing a client's copy never changes the master template.
4. Capture couple/family/vendor/committee details, event operations and VIP guest information.
5. Review the event rundown and generate a PDF, then monitor execution and incidents on the event day.

## Finance and controls

1. Set up client payment terms, invoices, paid/unpaid amounts and vendor commitments.
2. Track project expenses and vendor payment ownership.
3. Record backoffice transactions with balanced journals; use submission, approval, posting and reversal states as applicable.
4. Compare project budget, realized expense and operating profit.
5. Check closing prerequisites and review the financial reports.

## Public-demo limitation

The live demo is designed for presentation and UX review. It has synthetic records and browser-based persistence, not multi-user concurrency, real bank integrations, email/SMS delivery or a production accounting database.
